# Terms for the data in this repository

## Code
All files under `code/` are MIT licensed (see `LICENSE`).

## Derived result files
Files under `results/` are participant-level derived quantities computed from
ABIDE I. They contain no identifiable information: each row is keyed by the
ABIDE `FILE_ID`, which is the identifier the consortium itself publishes. They
are released under CC BY 4.0, **subject to the upstream ABIDE terms below**.

## Upstream data
Primary data are from the Autism Brain Imaging Data Exchange (ABIDE I),
preprocessed and redistributed by the Preprocessed Connectomes Project. ABIDE
data are shared for **non-commercial research use** under a Creative Commons
Attribution-NonCommercial-ShareAlike licence, and all contributing sites
obtained local ethical approval and participant consent.

Anyone reusing this repository must:

1. Honour the ABIDE non-commercial, share-alike terms.
2. Cite both the ABIDE data-sharing publication and the Preprocessed
   Connectomes Project resource (entries 36 and 37 of
   `manuscript/references.md`).
3. Not attempt to re-identify participants.

No raw imaging data are redistributed here.
